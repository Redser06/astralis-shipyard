# 🚀 Astralis Shipyard — Next-Gen Starship Foundry

> **Interactive 3D Starship Engineering, Bezier Spline Sculptor, R&D Tech Tree & AI Architect**

Astralis Shipyard is a visual starship design platform built with **React**, **Three.js (WebGL)**, and **Tailwind CSS**. It combines smooth aerospace starship hull generation, liquid glass UI aesthetics, modular component swap-outs, a 2D-to-3D spline curve sculptor, an R&D technology matrix, and a conversational AI ship architect.

---

## 🌟 Core Highlights

- **Procedural 3D WebGL Engine**: Render non-blocky, aerodynamic, lathed starships with continuous Bezier curves, customizable lighting, engine exhaust particles, and orbital drydock space stations.
- **360° Orbital Viewport**: Full horizontal and vertical camera orbit controls with distance zoom and auto-rotation.
- **Modular Component Hardpoints**:
  - **Drives**: Sublight Ion Pulse, Magnetoplasmadynamic, Fusion Torches & FTL Alcubierre Warp Rings, Graviton Singularity cores.
  - **Ordnance**: Gauss Railguns, Coherent Plasma Lances, Tachyon Beams, Quantum Singularity Torpedoes.
  - **Sensors**: Optical LADAR spines, Tachyon Radar domes, Quantum Entanglement arrays.
  - **Fuel Miniaturization**: Cryogenic Liquid H2 tanks to ultra-compact Zero-Point Energy cores.
- **Bezier Spline Sculptor**: Drag-and-drop 2D vector control points to dynamically sculpt hull profiles in real time.
- **R&D Tech Tree**: Interactive progression matrix with XP spending and unlocks.
- **AI Starship Architect**: Conversational prompt generator that dynamically reconfigures ship geometries and loadouts.
- **1-Click HTML Viewer Export**: Generates a self-contained, standalone `.html` 3D viewer file ready for sharing and offline browsing.
